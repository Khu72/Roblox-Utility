### What this project is *intended* to be

Roblox Utility is a **Windows helper app** that, depending on how you use it, may:

- Help run **more than one Roblox client** on one PC (by closing a singleton kernel handle in processes you already run—similar in spirit to what some community tools describe; Roblox may still disallow or detect related behavior).
- Store **your own** account cookies and **launch** the official Roblox client to join experiences (you are not asked to share credentials with the authors).
- Offer an **optional auto-clicker** that sends ordinary mouse input while you hold a button, intended for convenience—not for bypassing anti-cheat, exploiting, or automating gameplay in ways Roblox forbids.

The project **does not**:

- Modify Roblox’s installed game files or inject code into `RobloxPlayerBeta.exe`.
- Provide exploits, remote code execution, or “cheat” features aimed at unfair play.
- Operate Roblox’s servers or impersonate Roblox.

### Why some people describe tools like this as “not inherently” violating ToS (still not a guarantee)

Some users reason that **legitimate companion / launcher software** that only automates the OS (e.g. clicking) or manages **their own** session data, without tampering with the client or using stolen accounts, sits in a different category than **hacking or exploiting** the game. That is a **common informal distinction**, not a promise that Roblox agrees or that your account is safe.

**Roblox’s written rules are broad.** They can prohibit automation, multiple instances, or other behavior even when no “exploit” is involved. **“Not modifying the client” does not automatically mean “allowed.”**
